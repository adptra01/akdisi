## PART A — HOMEPAGE CONTENT

### Hero

**H1:**
> Solusi Aplikasi untuk Bisnis Properti dan Perumahan

**Subheadline:**
> Bangun sistem yang menyesuaikan proses bisnis organisasi Anda—mulai dari pengelolaan data, administrasi, layanan, hingga kebutuhan operasional yang lebih spesifik.

**CTA Primary:** Konsultasikan Kebutuhan Anda → `/contact/`
**CTA Secondary:** Lihat Portfolio → `/portfolio/`

### Problem Section

**Headline:**
> Ketika Proses Bisnis Bertumbuh, Sistem Harus Ikut Berkembang

**Cards:**
1. Data tersebar
2. Proses manual
3. Monitoring sulit
4. Laporan lambat
5. Sistem existing tidak sesuai

**Flow:**
1. Understand
2. Analyze
3. Design
4. Build
5. Implement
6. Improve

**Housing**
> Solusi untuk pengelolaan kawasan dan layanan penghuni.

**Developer**
> Solusi untuk mendukung proses bisnis developer.

**Property**
> Solusi untuk pengelolaan bisnis properti.

**Organization**
> Solusi untuk administrasi dan pengelolaan organisasi.

### Services Section

1. **Application Development** — Pembangunan aplikasi berdasarkan kebutuhan bisnis
2. **Business Process Digitalization** — Mengubah proses manual menjadi workflow digital
3. **Data & Administration Systems** — Sistem untuk data, member, unit, reporting
4. **Custom Business Solutions** — Solusi khusus yang tidak cocok dengan software generik
